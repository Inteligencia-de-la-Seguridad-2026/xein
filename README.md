# Xein

Laboratorio de la práctica Inteligencia de la Seguridad, Grupo N. Web Spring Boot, MySQL y simulador Python de pagos ficticios, desplegados en una VM Ubuntu Server 22.04.5.

- [Despliegue y pagos](LAB_DEPLOYMENT.md)
- [Topología, sensores y puntos de captura](NETWORK_TOPOLOGY.md)
- [Importación, acceso y diagnóstico de la VM](VM_HANDOFF.md)

El SQL, la configuración de la tarjeta ficticia, el JAR y la OVA se proporcionan por canal privado. Actualizar este repositorio no modifica automáticamente una VM ya importada.
